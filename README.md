# 32 点鞋垫电脑上位机

电脑通过蓝牙连接 CH592 网关，接收鞋垫串口转发的 32 点压力，并实时显示。

当前版本：**V1.0.0**

## 功能

- 扫描并连接广播名包含 `SENINSOLE` 的设备
- 订阅特征 `FFE4`，接收整帧通知
- 识别 `AA 55` 帧头，按小端解析 32 路 `uint16`，并校验 XOR
- 丢掉 `D5 5D` 状态包，电量与充电标志显示在界面底部
- 4×8 实时格子，颜色按原始 ADC 码 0～4095 从浅到深，当前最大点用蓝框标出
- 显示总和、最大点、接收帧率和 XOR 失败次数
- 命令行脚本每秒打印一次最新一帧

鞋垫原始帧约 250～300 Hz。网关只转发最新一帧，电脑侧大约 50 帧/秒。界面约每 30 ms 取一次最新值。

## 环境

- Windows 10 及以上，电脑带蓝牙
- Python 3.10 及以上

```powershell
pip install -r requirements.txt
```

## 使用

实时界面：

```powershell
python -u insole_ble_view.py
```

打开后会按关键字 `SENINSOLE` 自动扫描。也可以改关键字后点「连接」。设备静止约 30 秒会休眠，扫不到时先晃醒或重新上电，并断开手机上的蓝牙调试连接。

只在命令行打印：

```powershell
python -u insole_ble_print.py
python -u insole_ble_print.py --address 54:6C:50:54:89:DA
```

## 数据格式

一帧 67 字节，详见 `32点鞋垫串口协议.md`。

| 偏移 | 内容 |
|------|------|
| 0～1 | 帧头 `AA 55` |
| 2～65 | `ch00`～`ch31`，每个 `uint16` 小端，范围 0～4095 |
| 66 | 偏移 2～65 共 64 字节的异或 |

蓝牙服务 `FFE0`，通知特征 `FFE4`。67 字节能发出去要求 MTU 至少 70。连上后界面会显示协商到的 MTU。
