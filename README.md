# 32 点鞋垫电脑上位机

电脑通过蓝牙连接 CH592 网关，接收鞋垫串口转发的 32 点压力，并实时显示。

当前版本：**V1.0.2**

## 功能

- 扫描并连接广播名包含 `SENINSOLE` 的设备
- 订阅特征 `FFE4`，接收整帧通知
- 识别 `AA 55` 帧头，按小端解析 32 路 `uint16`，并校验 XOR
- 丢掉 `D5 5D` 状态包，电量与充电标志显示在界面底部
- 4×8 实时格子，颜色按原始 ADC 码 0～4095 从浅到深，当前最大点用蓝框标出
- 显示总和、最大点、接收帧率和 XOR 失败次数
- 「记录」按钮把每一次解析成功的帧写入 CSV，包含接收时间戳和 32 点原始值
- 命令行脚本每秒打印一次最新一帧

鞋垫原始帧约 250～300 Hz。网关只转发最新一帧，电脑侧大约 50 帧/秒。界面约每 30 ms 取一次最新值。

## 环境

- Windows 10 及以上，电脑带蓝牙
- Python 3.10 及以上

```powershell
pip install -r requirements.txt
```

## 使用

实时界面：

```powershell
python -u insole_ble_view.py
```

打开后会按关键字 `SENINSOLE` 自动扫描。也可以改关键字后点「连接」。连上后点「记录」，每一帧解析结果追加到程序目录下的 `insole_年月日_时分秒.csv`。再点一次停止并保存。断开连接时如果正在记录，也会自动保存。时间列是电脑收到该帧的本地时间，精确到毫秒；间隔不一定是固定的 20 毫秒。设备静止约 30 秒会休眠，扫不到时先晃醒或重新上电，并断开手机上的蓝牙调试连接。

串口体重秤：

```powershell
python -u scale_view.py
```

选择串口和波特率后点「打开串口」。秤按一行一个读数持续输出，例如 `-0.06,kg`，默认 9600、8N1。点「记录」后把接收时间和重量写入 `scale_年月日_时分秒.csv`。打开串口前先关闭其它占用该端口的串口工具。

只在命令行打印：

```powershell
python -u insole_ble_print.py
python -u insole_ble_print.py --address 54:6C:50:54:89:DA
```

## 数据格式

一帧 67 字节，详见 `32点鞋垫串口协议.md`。

| 偏移 | 内容 |
|------|------|
| 0～1 | 帧头 `AA 55` |
| 2～65 | `ch00`～`ch31`，每个 `uint16` 小端，范围 0～4095 |
| 66 | 偏移 2～65 共 64 字节的异或 |

蓝牙服务 `FFE0`，通知特征 `FFE4`。67 字节能发出去要求 MTU 至少 70。连上后界面会显示协商到的 MTU。

### V1.0.2

- 写盘放在单独线程，避免记录时卡住蓝牙接收。停止记录或断开连接时写完并关闭文件。

### V1.0.0

- 新增命令行接收程序 `insole_ble_print.py`：连接网关、打印 MTU，每秒打印 32 点、帧率、XOR 失败次数和状态包计数。
- 新增实时界面 `insole_ble_view.py`：4×8 显示 32 路原始值，并显示总和、最大点、帧率、XOR 失败次数和电量。
- 界面用单块画布绘制格子，边框粗细保持不变，只在数值或最大点变化时更新对应格子，避免刷新时文字被裁掉一帧。
